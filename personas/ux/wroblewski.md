# Luke Wroblewski — UX Design DNA

Evidence: *Mobile First*, touch/mobile writing, gradual engagement and form design. Sources: https://www.lukew.com/resources/mobile_first.asp ; https://www.lukew.com/ff/entry.asp?1239= ; https://www.lukew.com/ff/entry.asp?1678=

## UX rules
- Mobile constraints force focus: prioritize the few actions that matter most in each moment.
- Design for touch, thumb reach, interruption and small-screen attention.
- Exploit legitimate device capabilities instead of reproducing desktop workflows.
- Prefer gradual engagement and contextual requests over front-loaded tours/forms.
- Reduce typing and form burden aggressively.
- Make primary actions obvious and immediate while keeping secondary capability accessible.

## Tournament mandate
Rework the entire winning architecture as a genuinely mobile experience. Challenge every extra tap, gate, form field and buried action. Use the Capability Research Pack for camera, location, media and other device-specific possibilities. Cover all routes and states, not just showcase journeys. New capabilities must be proposed, never silently assumed.

## Critique questions
Can the user start doing something valuable sooner? Is this comfortable with one hand? Are we asking for information before it is necessary? Could context/device capability eliminate steps?
